## Suggested Next Steps for Today

1. **Decide on the core product** — Is PURPLE AI a web chat app, a browser extension, a mobile app, or something else?
2. **Set up a simple chat interface** — Add a basic chat UI to the landing page or as a new page (`chat.html`) so users can interact with an AI
3. **Pick an AI backend** — Options include OpenAI API, Anthropic Claude, or an open-source model
4. **Define the "memory" feature** — Since progress tracking and personalized learning are core features, decide how conversation history will be stored (browser localStorage, a backend database, etc.)
5. **Collect early access signups** — Connect the "Get Early Access" button to a form (e.g., Google Forms, Typeform, or a simple backend endpoint) instead of just an email link
